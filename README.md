# Toybox Together · v4.0.1

Читы, свободная камера и снапшоты для Put Your Toys Away Together! Поддерживается Windows x64 и Steam build **25826322**, версия игры **0.8.0.42**. Установщик проверяет контрольную сумму игрового файла.


Обновление 4.0.1 устраняет опасное чтение массива способностей внутри сетевого обработчика повторов. Обработчики подключаются только на время записи игроков и отключаются на паузе, после остановки и при смене карты. Обычная игра, запись камеры и воспроизведение не подключают их. Сетевые события записи сохраняют идентификатор способности и время; поиск в массиве выполняется при обновлении мода в игровом потоке.

Записи игроков поддерживают новую систему внешности: сохраняются постоянные имена тела и деталей. Повторы прежнего билда остаются совместимыми по движениям и действиям; их старые номера элементов одежды не имеют соответствия в новой системе, поэтому персонажи используют текущую внешность игры.

## Установка

1. Скачайте **Toybox-Together-v4.0.1.zip** из [релиза v4.0.1](https://github.com/VslyDream/toybox-together/releases/tag/v4.0.1). Закройте игру и распакуйте архив целиком в любую папку.
2. Откройте **Install.cmd**. Папка игры находится через Steam; если она не найдена, выберите её в окне.
3. Откройте ярлык **Toybox Together** на рабочем столе. Панель находится по адресу **http://127.0.0.1:18763/**. Python и другие программы отдельно устанавливать не нужно.

Backend работает без консольного окна. Он запускается ярлыком и автоматически при запуске игры с модом. Запустить и закрыть игру можно из панели. В Chrome или Edge локальную панель можно установить как приложение через меню браузера или появившуюся кнопку установки.

У страниц есть отдельные ссылки: **http://127.0.0.1:18763/?page=saves** — сохранения, **http://127.0.0.1:18763/?page=cheats** — камера и читы, **http://127.0.0.1:18763/?page=replays** — записи и повторы. Ссылки в боковой навигации открываются средней кнопкой мыши или Ctrl+кликом в новой вкладке. Все разделы читов расположены вместе; вложенные ссылки с эмодзи ведут к нужной группе на этой странице.

## Камера

Включение — **Ctrl+P**, **Num9** с включённым Num Lock или галочка на странице «Камера и читы». Num9 перехватывается модом в активном игровом уровне, чтобы не запускать сломанную штатную камеру. Панель показывает фактическое состояние.

| Управление | Действие |
|---|---|
| WASD | Полёт вперёд, назад и в стороны |
| Q / E | Вниз / вверх |
| Shift | Ускорение ×5 |
| Колесо | Скорость |
| Alt + колесо | FOV |
| Ctrl + колесо | Дистанция фокуса |
| Shift + колесо | Сила размытия |

Камера проходит через объекты и использует отдельный объект наблюдателя. Тело и игрушка остаются у персонажа; руки от первого лица и подсветка прицела скрыты. Можно снять собственного персонажа. Камера двигается и поворачивается при паузе мира, записи и повторе игроков. На сайте доступны скорость, работающий игровой FOV, чувствительность, отдельное сглаживание полёта и отдельное сглаживание поворота мышью. Значение 0 отключает соответствующее сглаживание. При переключении окна ввод прекращается. Выключение и переход между уровнями возвращают обычную камеру.

Камера реализована локально без требования прав хоста. Она должна быть установлена на компьютере клиента. Проверка настоящего Steam-коопа с двумя аккаунтами остаётся открытой; локальный сетевой стенд этой сборки не создал соединение. Аппаратные Ctrl+P, Num9, Shift и колесо также требуют короткой проверки в вашей обычной игровой сессии; реакции камеры на соответствующие события проверены внутри работающей игры.

В блоке **«Оптика и глубина резкости»** есть фокусное расстояние в миллиметрах (эквивалент сенсора шириной 36 мм, связано с FOV), дистанция фокуса в метрах и сила размытия объектива. Размытие 0 возвращает исходные настройки глубины резкости. Настройки оптики записываются вместе с полётом камеры. Видимое действие FOV и размытия проверено на кадрах настоящей игры.

## Игрушки и способности

В категории «Игрушки» включите инструмент галочкой или клавишей **0** (верхний ряд или Num0 с Num Lock). **ЛКМ** берёт ближайшие игрушки с пола; если прицел наведён на доступную игрушку на полке, берётся выбранная пачка с её стеллажа. Колесо меняет количество по 10 в пределах **10–200**. Если предметов меньше, берётся доступное число.

**ПКМ** выбрасывает пачку в направлении взгляда коротким потоком по восьми пространственным полосам. Летящие предметы этой пачки не расталкивают друг друга; столкновения с окружением сохраняются. Игра продолжает обрабатывать их штатную физику и попадание на полки. На сайте показан остаток очереди; кнопок «взять» и «бросить» нет.

«Вместимость рук» напрямую меняет действующую настройку инвентаря. «Сбросить» возвращает значение игры. «Способности без ожидания» снимает существующие кулдауны и отключает новые для актуальных способностей **1–7**. Кнопка Q для этого не нужна. Способности предварительно должны быть открыты; их уровни можно выставить в той же категории. Отключение режима возвращает обычную длительность кулдауна.

Читы разбиты на категории «Камера», «Игрушки», «Способности», «Магазин», «Вид и время». Для изменений мира, массового подбора и снапшотов нужен хост или одиночная игра. 

## Полки и шкаф под прицелом

На странице **«Камера и читы → 🏪 Магазин → 📦 Полки»**:

- **Количество** задаёт максимум для кнопок «Расставить на полки» и «Снять на пол». **Все** обрабатывает все доступные игрушки.
- **🎯 Заполнить шкаф под прицелом** заполняет выбранный шкаф целиком подходящими игрушками с пола, независимо от поля количества. Подойдите к шкафу или наведите свободную камеру на его корпус / игрушку. Учитываются план магазина и виды игрушек на рядах; остальные шкафы сохраняются.
- **Снять на пол** быстро снимает выбранное число игрушек с разных полок и равномерно распределяет их по найденным свободным участкам пола. Точки перемешаны случайно. Игрушки в руках сохраняются; анимация броска не тянет снятые предметы обратно к игроку.
- В раскрывающемся пункте **✨ С перелётом** остаётся штатная расстановка с анимацией. Она также использует выбранное количество / «Все».

Панель показывает фактически перемещённое количество. Если подходящих игрушек или свободных мест меньше, операция перемещает доступное число. Операции выполняются у хоста или в одиночной игре при снятой паузе. Во время изменения полок загрузка сохранения и повторные операции ждут окончания; повтор игроков нужно предварительно закрыть. Фрикамеру можно использовать при очистке.

В проверке на SkyKids Store 200 игрушек сняты примерно за **1,1–1,2 секунды**, все 952 игрушки на полках — за **4,4 секунды**. Скорость зависит от карты, количества и компьютера. Новая кнопка использует быстрый перенос через штатную регистрацию предметов, а не медленную очередь консольного `TS.Items.ClearShelfs`; сама консольная команда игры остаётся штатной.

Обновление поддерживает **SkyKids Store**, включая снапшоты и записи. Снапшоты и повторы предыдущего проверенного билда 25771484 сохраняются и доступны. При подготовке старого повтора номера игрушек сопоставляются с новым билдом по точным координатам и виду; неоднозначное сопоставление останавливает действие с понятной ошибкой. Новые массовые подборы записывают постоянное имя вида игрушки. Исходные архивы не переписываются.

## Записи и повторы

Откройте страницу **«Записи и повторы»** и выберите камеру или игроков. **«Начать запись»** создаёт новый дубль. **«Завершить запись»** сохраняет его в галерею.

| Клавиша | Действие |
|---|---|
| F6 | Начать запись; во время записи — пауза / продолжение |
| F7 | Начать загруженный повтор; во время повтора — пауза / продолжение. Без загруженного повтора подготавливает последнюю выбранную запись |
| F8 | Завершить запись или закрыть повтор |

**«Загрузить»** на карточке восстанавливает исходный уровень, объекты и настоящих персонажей и останавливает их на стартовых координатах в паузе. **«Начать»** запускает подготовленную сцену без повторной загрузки. **«Сначала»** восстанавливает исходное состояние игрушек и начинает заново; выбранный ракурс свободной камеры сохраняется. Кнопка **«Пауза»** останавливает время повтора. Скорость — от **×0.1 до ×4**.

Таймлайн показывает позицию и длительность. **Полёт камеры можно перематывать** ползунком, в том числе на паузе и после завершения. Для игроков он показывает прогресс; возврат через «Сначала» восстанавливает игрушки и способности из исходного состояния.

**Камера** записывается по координатам и поворотам, включая FOV, фокус и размытие. Запись ведётся до 60 выборок в секунду; между ними координаты и повороты интерполируются. Паузы исключены из времени записи.

**Игроки** записываются у хоста вместе с исходным снапшотом уровня, внешностью, координатами, взглядом, скоростью, режимами ходьбы и воздушного движения и действиями. Подбор, броски, инструмент и способности воспроизводятся через игровые системы и действительно меняют мир. Случайные столкновения участников повтора не сбивают координаты дорожки; анимация использует записанный режим движения и скорость.

Во время загрузки, воспроизведения, паузы и после завершения можно летать **свободной камерой**. Наблюдатель отделён от участников: его положение не меняет прицел и действия персонажей. Переключатель свободной камеры есть прямо над таймлайном; выключение возвращает вид за первым доступным участником. Временные игроки удаляются при закрытии повтора; оставшиеся у них игрушки выпускаются в мир до удаления.

В галерее отдельно переключаются **дорожка** и её **действия**, в том числе в ходе повтора. «Перезаписать» возвращает исходный мир, проигрывает остальные дорожки и записывает выбранного игрока. **«＋ Добавить игрока»** создаёт ещё один дубль человека, пока старые игроки выполняют свои действия. Так можно по очереди отыграть до четырёх персонажей в соло.

Галерея хранит изображение, название, длительность и дорожки. Есть переименование и восстанавливаемая корзина. Поддерживаются записи v2. Максимальная запись — **30 минут**, до **4 игроков** плюс отдельный наблюдатель. Первый промежуточный файл сохраняется примерно через 2 секунды, затем каждые 30 секунд. После аварийного закрытия доступна последняя успешно сохранённая часть; несохранённый хвост может быть потерян.

Полёт игрушек и эффекты рассчитывает игра, поэтому физический результат может отличаться при другой частоте кадров или пересечении действий. Штатная загрузка может пересчитать правильность ранее неверно расставленных игрушек. Настоящий Steam-кооп с двумя аккаунтами ещё не проверен; проверены дополнительные персонажи и последовательный отыгрыш в одной игровой сессии.

## Снапшоты

**«Снять и сохранить»** записывает текущее сохранение игры, координаты и поворот персонажа, карту, режим и состав игрушек в руках; движок снимает кадр самой игры без разрешений браузера. На время записи одиночная симуляция кратко приостанавливается и затем возвращается в прежнее состояние паузы.

Галерея содержит отдельные прохождения. Скриншот открывается крупно. Через «•••» доступны название, экспорт и корзина; удалённые снимки восстанавливаются из корзины. Экспорт **.toybox.zip** можно импортировать на другом компьютере с той же сборкой игры.

**«Загрузить»** автоматически выходит в меню, заменяет сохранения после завершения автосохранения и открывает нужную карту. При закрытой игре запускается Steam. Ручное «Продолжить» не требуется. Прямая TS.LoadGame не используется: проверка показала, что она перезаписывает возвращённое сохранение текущим состоянием перед перезагрузкой.

Перед заменой создаются резервные копии. Контрольные суммы всех файлов проверяются до записи. При ошибке снимок не публикуется; повреждённый снимок не может заменить сохранение. Запросы загрузки и записи выполняются по одному, ход операции виден на сайте.

Для закрытой игры есть отдельная команда «Сохранить последнюю запись на диске». Это явно обозначенный снимок без скриншота, координат и восстановления рук. Он доступен только для карты и режима, у которых уже есть файл сохранения.

Снапшот хранит постоянное состояние, поддерживаемое штатным сохранением игры. Активные эффекты способностей, скорость летящих предметов, таймеры анимаций и состояние удалённых игроков не восстанавливаются. В коопе загрузка хостом меняет уровень и может потребовать повторного подключения гостей. Эти сценарии в Steam-коопе не проверены.

## Обновление, откат и удаление

Закройте игру и откройте **Install.cmd** из нового пакета: настройки, снимки и повторы сохранятся. При сбое предыдущая версия возвращается автоматически. **Rollback.cmd** возвращает версию перед последней установкой. **Remove.cmd** удаляет мод и ярлык, сохраняя игровые сохранения, снапшоты, повторы и резервные копии.

Данные панели обычно находятся в `%LOCALAPPDATA%\ToyboxTogether`. Windows может перенаправить эту папку при установке из приложения; установщик сохраняет фактический путь в поле `dataRoot` файла `MyToyStore\Binaries\Win64\ToyboxInstalled.json` в папке игры. Снапшоты лежат в `snapshots`, повторы — в `replays`, резервные копии — в `backups`, настройки — в `config.json`. Сохранения игры: `%LOCALAPPDATA%\MyToyStore\Saved\SaveGames`. Игровые настройки экрана не входят в снапшот.

Если панель недоступна, откройте ярлык. Если игра работает без подключённого мода, закройте её и запустите снова. Если Steam обновил игру, установщик остановится до изменения файлов: нужен совместимый пакет. Наличие другого загрузчика модов установщик обнаруживает и не перезаписывает его. Дополнительные сведения находятся в `backend.log` рядом с данными панели и `ue4ss\UE4SS.log` рядом с игровым файлом.

Проверки и их ограничения перечислены в **VERIFICATION.md**. Пакет не содержит пользовательских сохранений, игровых скриншотов, тестовых профилей или абсолютных путей разработчика.


## Сборка из исходников

Готовый релиз включает Python и UE4SS; для установки он предпочтительнее исходного ZIP GitHub.

Для разработки нужен Python 3.12+; внешних Python-библиотек нет. Выполните:

```text
python -m unittest discover -s tests -p "test_*.py"
python tools/build_release.py
```

Сборщик загружает закреплённые официальные архивы Python и UE4SS, проверяет SHA256 и создаёт полный установочный пакет в `dist`. Чтобы собрать без сети, заранее поместите `python-embed.zip` и `ue4ss.zip` в `.build-cache`. Не запускайте Install.cmd непосредственно из исходного ZIP: в нём отсутствуют бинарные зависимости.

Сторонние компоненты и их лицензии перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
