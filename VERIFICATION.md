# Проверка v4.0.1

Поддерживаемый билд: Steam 25826322, игра 0.8.0.42, Windows x64.

Два дампа вылетов хоста показали одинаковый стек в UE4SS: lua_setiuservalue → UScriptStruct::construct → push_structproperty → индексирование TArray → Lua-обработчик сетевой функции. Чтение массива способностей в обработчике ServerTryActivateAbility выполнялось даже при выключенной записи повторов. В 4.0.1 обработчики подключаются только во время записи игроков; поиск способности в массиве перенесён из RPC в игровое обновление.

| Проверка | Результат |
|---|---|
| RPC при выключенной записи, записи, паузе, возобновлении и после остановки | 470 вызовов за проход, несколько проходов; без вылета и ошибок записи, события сохранены |
| Два персонажа | 50 RPC-вызовов; две дорожки с событиями обоих игроков |
| Повтор нового формата | Загрузка, внешность, воспроизведение с фрикамерой, завершение и удаление временного персонажа |
| Проверки данных | 17 тестов: сохранения, резервные копии, повреждение данных, совместимость повторов и новый формат внешности |
| Установка | 4.0.1 установлена; предыдущая версия сохранена для отката, контрольные суммы существующих игровых сохранений и галереи не изменились |
| Возможности v4 | Новая карта, полки по количеству, заполнение шкафа правильными видами игрушек, быстрое снятие с распределением по полу |

Проверки игры выполнялись на отдельной копии и отдельном профиле сохранений. Полная сетевая сессия двух Steam-аккаунтов не запускалась; тест штатной серверной RPC не заменяет проверку с другом. Исходный вылет не воспроизвёлся искусственным локальным вызовом старого обработчика. Исправление исключает подтверждённый опасный путь; отсутствие других вылетов не гарантируется.

Новые записи сохраняют имена активов внешности. Старые записи сохраняют движения и действия; старые числовые индексы одежды не имеют однозначного соответствия новым активам, поэтому используется текущая игровая внешность. Физика игрушек может отличаться при иной частоте кадров.

Повторяемые проверки данных: `python -m unittest discover -s tests -p "test_*.py"`.
